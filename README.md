# RFP 닥터 (제안요청서 검토 도우미)

제안요청서(.txt 또는 .pdf)를 넣으면 연습용 규칙에 어긋나는 곳을 찾아
"쪽 / 요청부서 내용 / 법령 원문과 조치" 표로 보여 주는 교육 실습용 도구입니다.

- **연습용 버전입니다.** 판단 기준은 연습용 가상 규칙 6가지이며, 실제 법령·규정이 아닙니다.
- `연습자료` 폴더의 문서는 모두 가상 자료입니다.
- 넣은 문서는 브라우저 안에서만 읽고, 서버로 보내거나 저장하지 않습니다.
- PDF 읽기에는 Mozilla의 공개 프로그램 [pdf.js](https://github.com/mozilla/pdf.js) 3.11.174(Apache-2.0)를 씁니다 (`lib` 폴더).
